# 福建理工大学电气与信息工程学院就业活动信息站设计说明

## 1. 项目目标

为福建理工大学电气与信息工程学院学生提供一个公开、免登录的就业活动信息站。网站集中展示当前进行或即将开始的企业宣讲会、招聘双选会，并按开始时间从近到远排列。

学生能够快速确认活动日期、时间、地点、举办方式、适用专业、企业、岗位、薪酬和网申入口。管理员能够手动录入信息、提交招聘链接，并审核自动抓取的候选内容。

## 2. 成功标准

- 学生打开首页后能够直接看到最近的招聘活动。
- 所有已发布活动按开始时间升序排列，进行中的活动优先展示。
- 每条活动能够进入详情页或详情视图，查看企业、岗位、薪酬、学历要求、地点、网申链接和原始来源。
- 自动抓取的内容不会直接公开，必须经过管理员审核。
- 网站能够免费部署，第一版不依赖付费服务器。
- 手机和桌面浏览器均可清晰使用。

## 3. 服务范围

网站仅服务福建理工大学电气与信息工程学院。

收录以下岗位：

- 电气
- 电力电子
- 智能控制
- 新一代电子信息技术
- 自动化
- 电子信息类
- 电子类
- 通信
- 微电子
- 嵌入式开发
- 半导体
- 理工科专业
- 不限专业

招聘信息与学院方向明显无关，且不属于“不限专业”的内容不进入待发布列表。

## 4. 用户与权限

### 学生

- 无需登录即可浏览。
- 可搜索企业、岗位或地点。
- 可按专业方向和活动类型筛选。
- 可查看活动详情和原始网申入口。

### 管理员

- 使用 GitHub 账号维护公开仓库。
- 可通过 GitHub Issue 表单手动录入结构化信息。
- 可提交企业招聘网址、公众号推文链接或原始文字。
- 可审核、修改、发布或驳回抓取结果。

第一版不建设独立账号体系和商业化管理后台。

## 5. 页面与交互设计

### 首页

- 顶部显示学院名称、招聘活动、信息来源和更新状态。
- 主标题为“近期招聘活动”，并说明已筛选的专业范围。
- 搜索框支持企业、岗位和地点关键词。
- 筛选项包括专业方向和活动类型。
- 主内容采用纵向时间轴。
- 日期位于最左侧，使用“9月21日”格式，并补充“今天、明天、星期几”等语义提示。
- 活动按开始时间从近到远排列。
- 页面滚动时，活动进入视口时轻微减弱，接近视线中心后恢复完整对比度；离开中心后再轻微减弱。
- 不支持滚动驱动动画或启用减弱动效时，所有内容始终保持完整清晰度。
- 活动默认不显示外框；鼠标悬停或键盘聚焦时，仅当前活动显示边框、浅背景和轻微阴影。

### 活动详情

详情包含：

- 活动标题与类型
- 开始时间和结束时间
- 举办方式与地点
- 企业名称与企业简介
- 岗位名称、专业要求、学历要求、工作地点和薪酬
- 网申链接或报名入口
- 原始来源链接
- 信息更新时间和审核状态
- “以企业或主办方官方通知为准”的提示

### 空状态与异常状态

- 没有符合筛选条件的活动时，提示清除筛选或更换关键词。
- 数据加载失败时显示重试入口，并保留上次成功发布的数据。
- 缺少薪酬、地点等字段时明确显示“未公布”，不推测内容。

## 6. 视觉规范

- 视觉方向为可信、克制、简洁的学院级数字刊物。
- 使用单一学院蓝作为强调色，避免多色渐变、玻璃拟态和大面积装饰。
- 通过字号、字重、留白、细分隔线和对齐体现层级。
- 页面采用统一小圆角；阴影只在悬停高亮时出现。
- 同时支持浅色和深色系统主题。
- 正文和交互控件满足 WCAG AA 对比度要求。
- 移动端将时间、活动信息和详情按钮重新排列为单列可读结构。

## 7. 技术架构

### 前台与数据

- 前台为静态网站，部署到 GitHub Pages。
- 已发布数据保存为仓库内的结构化 JSON 文件。
- 构建时读取 JSON，生成首页和活动详情页面。
- 第一版优先使用静态生成，不引入数据库。

### 管理录入

- 使用 GitHub Issue Forms 提供“手动录入”和“提交来源链接”两种表单。
- GitHub Actions 校验表单字段并生成候选数据文件或待审核 Pull Request。
- 管理员审核 Pull Request 后合并，网站自动重新构建并发布。

### 自动抓取

- GitHub Actions 按计划运行抓取任务。
- 每个来源使用独立适配器，避免一个来源变更影响其他来源。
- 抓取结果先经过字段标准化、专业相关性筛选和去重。
- 合格内容进入待审核 Pull Request，不直接发布。
- 首批来源：
  - 福建理工大学就业网：`https://fjut.jysd.com/`
  - 福建就业网：`https://www.fj99.org.cn/bys/#/`
  - 福州大学人才招聘相关页面：`http://fjrclh.fzu.edu.cn/`
  - 闽江学院就业信息网：`http://job.mju.edu.cn/`
  - 福建农林大学就业信息网：`http://career.fafu.edu.cn/`

公众号文章可能存在访问限制，第一版以管理员提交链接并人工补录为主，不承诺稳定自动抓取。

## 8. 数据模型

每条活动至少包含：

```json
{
  "id": "稳定且唯一的标识",
  "title": "活动名称",
  "eventType": "宣讲会或双选会",
  "startAt": "带时区的开始时间",
  "endAt": "带时区的结束时间或 null",
  "mode": "线下、线上或混合",
  "venue": "地点或线上平台",
  "companies": [],
  "jobs": [],
  "majorTags": [],
  "applicationUrl": "网申或报名链接",
  "sourceUrl": "原始来源链接",
  "sourceName": "来源名称",
  "reviewStatus": "draft、approved 或 rejected",
  "reviewedAt": "审核时间或 null",
  "updatedAt": "更新时间"
}
```

岗位对象包含岗位名称、薪酬、学历要求、专业要求、工作地点和招聘人数。无法从来源确认的字段使用 `null`，前台显示“未公布”。

## 9. 筛选与去重规则

- 专业匹配采用关键词规则，不使用大模型执行确定性的路由和重试。
- 标题或岗位中出现目标专业关键词时进入候选列表。
- 明确写有“不限专业、专业不限、理工科”等内容时进入候选列表。
- 去重优先比较来源链接；来源链接不同则比较规范化标题、企业、开始时间和地点。
- 自动规则无法确定时标记为“需要人工判断”，不自动发布。

## 10. 错误处理

- 单个来源抓取失败不终止其他来源。
- 抓取失败记录来源、时间和错误摘要，不记录账号密钥。
- 来源页面结构变化时，保留上次成功数据并创建维护提醒。
- 无效日期、缺失标题或缺失来源链接的数据不能进入待审核列表。
- 网申链接发布前检查协议和可访问性，失效链接在前台标记而不是静默删除活动。

## 11. 测试与验收

- 数据模型校验测试：必填字段、日期格式、URL 和状态枚举。
- 筛选规则测试：每个目标专业、不限专业和明确无关专业均有样例。
- 去重测试：相同来源和不同来源的重复活动均能识别。
- 排序测试：进行中、当天、未来和跨日活动顺序正确。
- 抓取适配器测试：使用保存的页面样本，避免测试依赖实时网站。
- 前端测试：搜索、筛选、详情入口、空状态和错误状态。
- 可访问性测试：键盘操作、焦点样式、对比度和减弱动效。
- 响应式检查：手机、平板和桌面主要断点。
- 发布前运行项目的 lint、类型检查、测试、构建和链接检查。

## 12. 部署与成本

- 代码和公开招聘数据存放于公开 GitHub 仓库。
- GitHub Pages 承载前台。
- GitHub Actions 负责校验、抓取、构建和部署。
- 第一版不使用付费数据库或服务器，目标月成本为 0 元。
- 若未来需要多人独立后台、细粒度权限或大量实时数据，再评估 Supabase 等服务。

## 13. 第一版明确不做

- 学生账号、收藏和个性化推荐
- 微信或短信通知
- 企业自行注册和发布
- 简历投递与简历存储
- 自动发布未经人工审核的抓取内容
- 对受登录、验证码或反爬限制页面进行绕过

## 14. 已确认决策

- 服务范围仅限福建理工大学电气与信息工程学院。
- 使用公开 GitHub 仓库和 GitHub 账号维护。
- 自动抓取内容先审核后发布。
- 第一版采用免费静态架构。
- 首页采用完整日期的纵向时间轴。
- 渐变由滚动位置驱动，活动位于视线中心时必须完整清晰。
- 信息框仅在悬停或键盘聚焦时显示。
